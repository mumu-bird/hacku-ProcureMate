# 验证与证据边界

核心验证通过 45 个 Node 测试，浏览器通过 5 个端到端测试，TypeScript 检查与生产构建通过。详细机器结果存储在 artifacts。后续代码改动后须重新运行相关检查。

| 验证       | 实际检查                                                                       |
| ---------- | ------------------------------------------------------------------------------ |
| 费用与来源 | 16 个商品、正整数港币分、来源链接、采集时间；运费独立计入                      |
| 指令边界   | 不可信需求不能改变授权或目录金额；规则模式保留固定数量                         |
| 交易闭环   | 授权、预算预留、扣款、订单、收货、退款与显式退货                               |
| 拦截       | 超预算、过期、撤销、品类/商户/地址越界、替换限制、需求不匹配                   |
| 重复与并发 | 同一订单不重复付款；两个任务不能突破累计预算                                   |
| 撤销与报价 | 支付授权期间撤销或报价版本变化，不能继续扣款                                   |
| 不确定结果 | 超时保留预算；明确核对，不重新发起付款                                         |
| 库存       | 领用不产生负库存；收货/退货幂等；在途量阻止重复补货                            |
| 用户权限   | 成员不能授予/撤销授权、申请退款；角色 cookie 不能提升权限                      |
| 支付回调   | 已验证事件重复与乱序处理；金额不匹配拒绝；未配置接口拒绝无签名请求             |
| 可核对记录 | 检查记录链；篡改记录可以被当前链检测                                           |
| 浏览器     | 活动采购、拦截、退款、补货、岗位模板、错误输入、跨站来源拒绝、移动端无横向溢出 |

## 未完成的验证

新增闭环回归覆盖支付金额/币种、回调与网络响应冲突、支付编号恢复、渠道混用、并发核对的单次扣款、两个进程各写 100 条审计记录与完整链导出。浏览器已验证领用触发第二笔补货及其收货。费用规则按观察到的 HK$400 标准免运费门槛计算，边界包含在测试中。详细参赛核对见 `competition-readiness.md`。

- 没有模型和 Stripe 测试凭证，尚未进行真实外部接口测试。模拟支付器验证了状态与预算流程。
- 没有实际 HKT 下单、公司支付账户或积分账户，目录快照不是实时成交报价。
- 尚未做五人任务测试。学生角色任务测试也不能证实企业需求与付费意愿。
- 当前测试不证明绝对安全、任何并发规模下的可靠性或商业效果。
- 标准运费和商品页面存在特殊规则，需要真实商户报价才能正式执行。

## 用户任务测试协议

执行材料及明确的共同计时终点见 `user-study-protocol.md`，空白记录见 `user-study.csv`。官方未规定五人样本；五人是本项目计划。当前真人测量记录为零。

使用同一活动采购条件：参与人数、总预算、商品类别、收货地址和费用来源固定。参与者编号 P01–P05，不记录实名。交替安排人工/代理顺序，避免第二次任务的熟悉度全部归因于代理。

人工方法自行比较提供的商品来源与费用，代理方法使用工作台。各自记录耗时、点击/步骤数、完整支出、条件遗漏或越界错误。发生中断、帮助或任务改变须记录备注。数据进入执行记录页的录入表后才能用于路演，不事先填入效果指标。

## 新增选品验收

默认十人 HK$2,500 任务返回三套预算内礼品，不再遗漏 HK$1,380 的 Tritan 组合。预算降至 HK$1,500 时只提供一套可行方案。至少 500 ml 且来源明确标注保温时只返回 500 ml 真空杯；超过目录已知容量的需求停止规划。模型偏好超预算商品也不能挤掉预算内候选；重复 ID 去重。支付规则独立拦截需求超预算、数量变化或规格不符。新增浏览器流程验证输入规格、改变偏好、查看排除原因与报价记录。模型响应测试使用夹具，不是实际 AI 调用。

外部接口验证命令 `npm run verify:integrations` 加载被 Git 忽略的 `.env.local`，在独立数据库执行，报告不保存密钥和原始接口错误。没有配置时退出码 2；当前报告见 `artifacts/integration-verification.json`。只有实际模型调用校验成功、Stripe 沙箱全部阶段成功才返回 0。该脚本不验证 webhook、商户订单或企业支付授权。

## 对照工具验证

五项核心检查覆盖负责人权限与主持人确认、固定试验顺序、操作 ID 重放去重、结果封存、不覆盖已有参与者、错误答案与放弃保留、来源变更停止、空样本无指标及不同快照分组。新增浏览器流程完成代理任务、封存后再进行人工路线的放弃，确认报告没有配对成功数据。第一条路线校验在第二条结束后展示。

自动化使用独立临时数据库和明确标注的夹具备注。自动化运行时间、人数和成本不会进入实际真人数据库，也不作为官方人工路线证据。页面截图 `study-empty.png` 展示空状态，不用夹具生成成功效果截图。
